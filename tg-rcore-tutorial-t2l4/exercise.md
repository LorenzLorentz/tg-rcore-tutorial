# tg-rcore-tutorial-t2l4 练习说明：可插拔调度算法实验套件

本章**基于 `tg-rcore-tutorial-ch8` 继续开发**，目标是把当前单一调度器改造成“可插拔策略 + 统一观测 + 可比较 workload”的实验平台。

## 必做任务

1. 抽象统一调度器接口：
   - `enqueue(task)`
   - `pick_next()`
   - `on_tick()`
   - `on_block()`
   - `on_wakeup()`
2. 把调度粒度明确为线程，并在代码中给出理由。
3. 为 FCFS / SJF / RR / MLFQ / CFS-like（简化）准备统一的状态承载方式。
4. 实现统一 trace collector，记录时间戳、队列长度、上下文切换和运行片段。
5. 设计 workload：
   - CPU-bound
   - IO-bound
   - 交互型
   - 混合型
6. 输出统一比较指标：
   - 平均等待时间
   - 平均周转时间
   - 吞吐量
   - P95 / P99 交互延迟
   - 饥饿发生次数

## 建议扩展

- MLFQ 的提升 / 下降策略参数化
- 时间片动态调整
- burst prediction
- 负载变化下的稳定性分析

## 验收要求

- 能在终端打印不同调度策略的比较表
- 能解释每个指标的定义与统计口径
- 能说明为什么 `ch8` 比 `ch5` 更适合作为本章基线
